# 系统维护黑框修复

本修复只把 `SampleRoomLifecycleRunner` 计划任务改成真正的无窗口后台运行方式。
它不重新部署系统，不运行数据库迁移，也不修改订单、附件、恢复点或维护凭据。

## 操作

1. 先确认“系统管理”页面没有正在执行备份、恢复点或其他维护任务。
2. 解压修复 ZIP，不能直接在 ZIP 内运行。
3. 双击 `Repair-LifecycleRunner-Window.cmd`。
4. Windows 询问是否允许修改时，选择“是”。
5. 等待显示 `Repair succeeded`，然后按任意键关闭修复窗口。
6. 回到系统管理页面，等待 10 至 20 秒后刷新状态。

修复时，原来长期显示的黑色 Runner 窗口会自行关闭。修复结束后不会再出现长期运行的黑框；以后登录或重启服务器后，Runner 会自动在后台启动。

如果提示仍有维护任务，请等待该任务完成后再运行。任何其他错误都不要重新部署系统，请保留窗口并截图交给维护人员。
